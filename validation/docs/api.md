# Документация к API

## Запросы


### Проверка состояния сервиса
Возвращает состояние сервиса

```bash
GET /health
```

- Статус код - **200 OK**

- Тело ответа 
    ```json
    {
        "status": "AVAILABLE"
    }
    ```

### Проверка валидности метро в данном городе

```bash
POST /api/metro
```

Заголовки
- Content-type: application/json

- api-key: ...


Тело запроса

```json
{
    "city": "Москва",
    "metro": "Бауманская"
}
```

- Статус код - **204 No Content**

- Если станиця метро не валидна, например, не существует - **404 Not Found**

- Если ```city == ""``` или ```metro == ""``` - **400 Bad Request**
