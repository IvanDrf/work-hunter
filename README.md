# Work-Hunter
Work-Hunter - это веб приложение, созданное для работодателей и соискателей.

## Микросервисы
- **Авторизация (auth)**
    - отвечает за регистрацию пользователей, подтверждение почты, вход в аккаунт.

- **Пользователи (users)**
    - отвечает за хранение информации о пользователях: имя, фамилия, название компании и т.д.

- **Вакансии (vacancy)**
    - отвечает за управление вакансиями: создание, редактирование, удаление, модерация вакансий.

- **Контент (content)**
    - отвечает за хранение различных файлов: аватарки пользователей, резюме в формате pdf.

- **Отклики (applications)**
    - отвечает за отклики на вакансию. Позволяет посмотреть отклики пользователя и отправляет сообщение в брокер для сервиса Вакансий (vacancy) для обновления счетчика откликов на данной вакансии.
