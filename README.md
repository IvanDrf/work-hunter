# Work-Hunter
Work-Hunter - это веб приложение, созданное для работодателей и соискателей.

### Описание каждого микросервиса

- **Авторизация (auth)** - отвечает за регистрацию пользователей, подтверждение почты, вход в аккаунт.

- **Пользователи (users)** - отвечает за хранение информации о пользователях: имя, фамилия, название компании и т.д.

- **Вакансии (vacancy)** - отвечает за управление вакансиями: создание, редактирование, удаление, модерация вакансий.

- **Контент (content)** - отвечает за хранение различных файлов: аватарки пользователей, резюме в формате pdf.

- **Отклики (applications)** - отвечает за отклики на вакансию. Позволяет посмотреть отклики пользователя и отправляет сообщение в брокер для сервиса Вакансий (vacancy) для обновления счетчика откликов на данной вакансии.

- **Валидация (validation)** - отвечает за корректность введеных даннных, например: метро. 

Воркер **Email** отвечает за отправку писем по почте для верификации акаунта.

## Описание структуры проекта

По мере разработки структура может меняться.

``` bash
├── applications # сервис откликов
├── assets # файлы для README.md
├── auth # сервис авторизации 
├── contributions # правила коммитов
├── LICENSE
├── pkg # сгенерированные файлы для контркатов на go, python
├── protos # контракты gRPC proto
├── README.md
├── usеrs # сервис пользователей
├── vacancy # сервис вакансий
└── validation # сервис валидации
```
